# PureGreen Logistik 🥬🚛

**PureGreen Logistik** adalah landing page distributor dan supplier sayuran hidroponik premium untuk restoran, cafe, hotel (HORECA), dan supermarket.

Website ini dibuat dengan **React**, **Vite**, **TypeScript**, dan **Tailwind CSS**.

---

## 🚀 Fitur Utama

- 🌿 **Mobile-First Responsive Design**: Tampilan dirancang optimal untuk pengguna smartphone & desktop.
- 📱 **Pemesanan Cepat via WhatsApp**: Form dinamis yang langsung menyusun format pesan WhatsApp lengkap dengan detail nama usaha, jenis sayur, dan kuantitas pesanan.
- 🥗 **Katalog Sayuran Segar**: Menampilkan foto asli dan informasi masa simpan serta siklus panen sayuran hidroponik (Selada Romaine, Pakcoy Green, Selada Keriting, Bayam Brazil).
- 💰 **Daftar Paket Harga Grosir**: Estimasi paket untuk Resto, Cafe/Catering, dan Supermarket.
- ❓ **Tanya Jawab (FAQ Accordion)**: Menjawab pertanyaan umum terkait minimal order, jaminan bebas pestisida kimia, sistem termin pembayaran B2B, dan contract farming.
- 📍 **Lokasi Farm & Integrasi Google Maps**: Kemudahan navigasi ke lokasi pusat distribusi.
- 📤 **Fitur Bagikan (Share Modal & Copy Link)**: Berbagi ke media sosial (WhatsApp, X/Twitter, Facebook).
- 📌 **Sticky CTA Button**: Tombol pesan melayang yang muncul saat halaman digulir.

---

## 🛠️ Tech Stack

- **Framework**: [React 18](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Language**: TypeScript

---

## 💻 Menjalankan Secara Lokal

1. **Clone repository ini**:
   ```bash
   git clone https://github.com/solusilokal/PureGreen-Logistik.git
   cd PureGreen-Logistik
   ```

2. **Install dependensi**:
   ```bash
   npm install
   ```

3. **Jalankan development server**:
   ```bash
   npm run dev
   ```
   Buka browser di `http://localhost:3000`.

4. **Build untuk produksi**:
   ```bash
   npm run build
   ```
